# 兼容性测试任务与设置面板设计

## 目标

解决“一键测试插件支持”在测试期间阻塞 Blender 界面、没有可见进度的问题；减少 3D 视图侧边栏的低频配置入口；移除顶部栏的“插件库”快捷入口。

## 兼容性测试任务

### 任务模型

兼容性测试改为 Blender 模态操作符驱动的分步任务，而不是在一次 `execute` 调用中遍历全部插件。每个计时器事件只测试一个插件，并在事件之间把控制权交还给 Blender，从而允许界面重绘和响应输入。

任务在开始前建立稳定的目标列表，记录总数、已完成数、成功数、失败项和当前插件名称。每个目标继续沿用现有的真实加载、状态恢复和残留清理逻辑；只改变调度方式，不弱化测试含义。

### 可见状态与取消

侧栏在任务执行时显示当前进度（如 `3 / 18`）、当前插件名称、进度条和“取消”按钮。状态栏同步显示同一进度，方便用户在侧栏未展开时获知状态。

“取消”不会中断正在运行的插件加载或卸载，避免留下半完成状态。它设置取消请求，当前插件处理结束后停止后续任务，并将已完成项目的结果写入数据库、报告和界面。取消后的摘要会明确显示已完成数量与未完成数量。

### 下次运行

测试入口弹窗提供两种范围：

- **继续未完成项**：仅测试没有本轮结果的项目，默认选择；已完成结果保留。
- **全部重新测试**：清除本轮目标的旧实测状态并重新测试全部可测插件。

“也测试已启用的插件”保留为独立选项；对已启用插件的停用、复测和恢复逻辑保持现有安全语义。没有可测试项目时直接显示说明，不启动任务。

### 结束与异常处理

无论完成、取消或发生未预期异常，任务都必须移除计时器、清空状态栏、保存已处理记录、刷新列表，并生成可查看的测试摘要。失败项目继续进入现有扫描报告和日志；取消不被报告为错误。

## 界面信息架构

### 3D 视图侧边栏

保留高频插件管理：库连接状态、搜索和筛选、插件列表、插件详情、批量操作、导入、在线商店、更新、扫描报告，以及兼容性测试入口和运行时进度。

从侧边栏移除低频的“迁移与启动控制”子面板。库级下拉菜单不再承载低频维护功能，以免与设置面板重复。

### 插件偏好设置

在“编辑 → 偏好设置 → 插件 → 插件库管理器”中收纳以下低频配置和维护：设备名称、库路径、启用/修复挂载、卸载挂载、刷新、诊断、启动同步策略、迁移收编、清理失败插件残留，以及官方商店目录关联。

现有操作符与数据存储不变，只移动入口；这确保旧流程和自动化调用仍兼容。

### 顶部栏

删除 3D 视图顶部栏的“插件库”按钮、分类快捷按钮及其弹出列表。对应模块不再注册顶部栏回调或相关快捷操作符；侧边栏和偏好设置成为唯一界面入口。

## 测试策略

- 为任务状态和目标筛选提取不依赖 Blender UI 的小型逻辑，覆盖“继续”与“重试全部”范围、取消后的摘要、已启用项目筛选。
- 用 Blender 兼容的模拟上下文测试模态调度：一次 tick 仅处理一项、取消在当前项之后生效、终止时清理状态。
- 更新 UI 冒烟测试，确认设置面板含迁移和维护入口、侧边栏不再渲染迁移面板、顶部栏不再注册。
- 运行现有单元测试和可用的 Blender 集成/UI 冒烟检查。

## 非目标

- 不使用后台线程调用 Blender API。
- 不改变每个插件实际加载/恢复的判定标准。
- 不删除现有低频功能或改变共享库、本机配置和设备配置的数据边界。
