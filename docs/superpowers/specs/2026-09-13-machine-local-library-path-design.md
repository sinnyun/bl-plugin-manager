# 每台电脑独立保存插件库路径设计

## 背景

插件库管理器目前把 `library_path` 作为 Blender 插件偏好保存。用户通过同步工具在多台电脑之间同步 Blender 配置；不同电脑的盘符和目录不同，因此同步后的 `userpref.blend` 会把另一台电脑的插件库路径带到本机，导致插件虽然能加载，但插件库无法扫描、挂载或管理。

共享插件库中的插件文件、分类、备注、别名、收藏、启动标记和兼容性记录仍应继续同步。只有指向共享库的本机文件系统路径必须按电脑隔离。

## 目标

- 每台电脑独立保存自己的插件库路径，Blender 配置同步不再覆盖它。
- 同一台电脑上的不同 Blender 版本共用该本机路径。
- 从 1.0.3 升级时尽量无感迁移已有有效路径。
- 不修改、搬移或删除共享插件库中的任何内容。
- 路径不可用时安全降级，不创建从其它电脑同步来的错误目录。

## 非目标

- 不改变 `.pm/library.json` 的结构或同步方式。
- 不为每台电脑拆分分类、备注、收藏、自启标记等共享数据。
- 不要求各电脑使用相同盘符。
- 不实现远程同步服务或设备账户系统。

## 方案

### 本机配置位置

新增专用模块负责本机配置读写。Windows 上使用：

```text
%LOCALAPPDATA%\BlenderPluginManager\machine.json
```

该位置不属于 Blender 的漫游配置目录，因此不会随当前 Blender 同步规则传播。配置文件采用 UTF-8 JSON，仅保存当前需要的字段：

```json
{
  "schema": 1,
  "library_path": "D:\\path\\to\\blender_addons"
}
```

在非 Windows 平台或 `LOCALAPPDATA` 不可用时，使用平台对应的本机用户数据目录作为后备位置。写入通过同目录临时文件加原子替换完成，避免 Blender 异常退出留下半个 JSON 文件。

### Blender 偏好属性

`library_path` 继续作为界面属性供现有操作符和面板使用，但标记为不随 Blender 偏好持久化。运行时值由本机配置加载。

其他界面状态和启动控制设置维持现状。本次修复只隔离插件库路径。

### 启动与迁移数据流

插件注册后、执行自动同步与自动挂载前，按以下顺序解析路径：

1. 如果本机配置包含非空路径，将它加载到运行时偏好中。本机配置具有最高优先级。
2. 如果尚无本机配置，并且旧 Blender 偏好中的路径指向一个真实存在的目录，则把该路径迁移到本机配置并继续使用。
3. 如果尚无本机配置，且旧路径不存在或为空，则清空运行时路径，不创建该目录，也不进行自动挂载。界面明确提示用户为本机选择插件库目录。
4. 用户通过现有目录选择操作符成功连接一个库后，立即把规范化后的路径写入本机配置。

迁移只接受已经存在的目录，避免把另一台电脑的无效盘符误创建为空库。升级后每台没有可迁移有效路径的电脑只需重新选择一次。

### 路径更新与错误处理

- UI 修改路径后的回调负责保存本机配置；启动加载时使用保护标记，避免把过渡值重复写回。
- 本机配置缺失属于正常首次运行状态。
- JSON 损坏、字段类型错误或读写失败不得阻止插件注册。插件应输出可诊断信息，并把路径视为未配置。
- 本机路径后来暂时不可用时保留配置值，但跳过自动挂载；界面显示未挂载状态。这样网络盘恢复后不必重新选择。
- 用户主动选择的新目录仍沿用现有安全校验：只有成功连接后才更新运行时值和本机配置。

## 组件变化

- 新增 `bl_plugin_manager/machine_config.py`：确定本机配置位置、读取、校验和原子写入。
- 修改 `bl_plugin_manager/preferences.py`：路径属性不再随 Blender 偏好保存，并在有效用户更改后写入本机配置。
- 修改 `bl_plugin_manager/__init__.py`：注册阶段先恢复或迁移本机路径，再执行现有自动挂载流程。
- 修改 `bl_plugin_manager/operators.py`：目录选择成功后确保本机路径落盘，写入失败时向用户报告且不伪称完整成功。
- 修改版本常量、插件版本和 README，发布为 1.0.4。

## 测试设计

自动测试至少覆盖：

1. 本机配置路径覆盖模拟同步而来的另一台电脑路径。
2. 本机配置不存在时，有效旧路径会迁移并保存。
3. 本机配置不存在时，无效旧路径不会迁移、不会被创建。
4. 损坏 JSON 安全回退，不阻止插件注册。
5. 保存后重新加载得到相同 Unicode/网络路径。
6. 原有 16 项回归测试和 161 项端到端测试全部通过。
7. 1.0.4 安装进当前 Blender 后，插件启用、版本、操作符注册和本机路径恢复均通过实机检查。

## 发布与回滚

构建 `dist/bl_plugin_manager-1.0.4.zip`，使用现有安装流程替换各 Blender 用户插件目录中的管理器代码。安装前不改动当前插件库；安装失败可重新安装已有的 1.0.3 包回滚。首次启用 1.0.4 时若当前电脑没有有效旧路径，用户需要在侧边栏重新选择本机插件库目录一次。
