# Blender 插件库管理器现行需求

适用于 2.3 系列。历史设计文档保留当时的决策和技术背景，用户可见行为以本页及 README 为准。

## 产品范围

管理器在 Blender 中发现、整理、分组启停和更新传统插件、扩展与 Blender 内置插件。单机用户只需要选择一个库。多设备用户可用自己的同步工具共享资料库，每台设备保留自己的安装路径、启用策略与分组开关状态。管理器不提供文件同步服务，也不自动合并第三方同步工具产生的冲突副本。

## 库和 Blender 配置

- 选择目录时预览现有插件、待收编项目和旧库迁移。确认「启用管理」后才初始化或挂载。首次收编散放目录默认复制，原件留在原处。
- 在后台读取目录预览和插件元数据。启用管理或启动恢复时如需迁移旧库，也在后台完成。准备期间显示任务状态，完成后挂载并应用设备配置。
- 启用管理只涉及扩展仓库、自定义脚本目录和库内插件启用清单。停止管理先保存可读取的设备配置，再恢复这三项范围的默认行为，且不得停用 Blender 自带内置插件。系统联网权限及其它 Blender 偏好由用户管理。
- 切库前先验证目标，挂载失败须恢复原配置。启动时若已启用的库不可用，保留路径与接管意图，显示离线并允许重连；自启同步不得创建缺失目录。
- 启用意图表示用户请求，运行结果记录实际状态。文件暂缺或无法加载时保留意图。自启策略只在已启用并挂载的库运行，同时支持单插件自启与分组自启。启用强制自启策略时，标记决定启动时实际加载的库内插件（不强关内置插件），设备启用清单仍保留用户意图。
- Blender 自带核心插件（`scripts/addons_core/`）采用虚拟链接管理，不复制文件进库、不可移入回收站，升级 Blender 后自动跟随新版；导入或收编外部插件时自动拦截与内置插件同名的冲突项。

## 资料、身份和升级

| 数据 | 所属范围 |
| --- | --- |
| 稳定插件身份、别名、分组定义与成员归属、备注、标签、收藏 | 共享资料库 |
| 启用意图、受管仓库与脚本目录 | 每设备配置 |
| 安装相对路径、版本、兼容范围、模块、实际启用、自启、分组开关/自启和实测结果 | 本机状态 |

- 不同字段或不同分类的独立修改应合并。同一字段改成不同值时保留已发布值，将本次建议值写入本机冲突记录，并提示刷新。不同设备上的实际安装版本不得互相覆盖。
- 扩展 manifest ID 相同可沿用资料。两个明确不同的 ID 即使目录和名称相同，也要分开记录。传统插件没有稳定 ID 时，名称与目录只作为匹配线索。
- 支持迁移 1.x schema 1 与 2.0/2.1 schema 2 的 `library.json`。保留共享资料和旧自启标记，成功保存后只读归档原文件。损坏或更高 schema 保留原件、拒绝写入。
- 文件级同步可能传播移动、替换和移除。界面需明确区分「在此设备停用」和「从库移入回收站」。恢复从原路径进行，原路径已被占用则保留回收站原件并提示。

## 操作及界面

- 侧栏面向日常工作台，顶部提供连接状态与工作分组（支持多组叠加开关、交集共有插件防误关、常驻组、独占切换与分组自启），中部提供搜索、来源/状态筛选与插件列表，下方提供默认展开的插件详情（含中文别名与多分组分配），低频的导入、商店、批量与兼容性测试折叠收纳。偏好设置集中管理库与设备、原生界面双语名称覆写、内置插件虚拟链接、启动策略、收编和诊断。
- 支持以纯运行时方式在 Blender 原生「偏好设置 → 插件」与「获取扩展」显示中英双语名称（默认 `原名 (中文名)`），不修改任何第三方插件文件或底层元数据，关闭开关或停用管理器后无痕恢复。
- 勾选与启停采用不同控件（日常默认隐藏勾选框，开启批量模式后在主面板与批量区显示）。批量操作严格作用于当前筛选结果中的勾选项，全选当前结果会替换旧勾选，关闭批量模式清空勾选，零勾选时没有隐式目标。工作分组列表顶部固定提供默认「全部插件」行用于一键切回全部。列表展示短状态，详情提供版本范围、来源提示、分组归属、自启及错误。
- 兼容性实测结论跟随本机 Blender 环境、安装版本和元数据指纹。切换环境或更新文件后需重新测试。分步任务每次处理一个插件，取消在当前加载/卸载结束后生效。
- 更新检查只为来源已确认的安装推荐同仓库更新。其它来源必须单独预览和确认。下载可取消，已完成项保留，失败项可重试；应用前核对插件 ID 和版本，替换或加载新版本失败时恢复原文件和此前启用状态。

## 发布验收

- 本机首次预览、接管、切库失败、离线重连、停止后重启。
- 两台设备共享资料并使用不同插件目录及安装版本。验证同字段冲突、不同字段保存、插件换装和缺失意图保留。
- schema 1/2 升级、未知 schema 拒绝写入、导入失败、回收站恢复、更新加载失败回滚、下载取消和重试。
- Python 单元测试、静态入口核对、实际 Blender 隔离回归及端到端、UI 绘制冒烟、ZIP 完整性和安装脚本验证。
- 发布前在最低支持版本与目标版本的真实窗口检查默认及窄侧栏、显示缩放和长名称，使用真实仓库检查联网与下载。隔离测试应验证真实用户配置未变。
